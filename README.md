# 漫游搭子 · Roamio

以 Oslo 与 Bergen 五日旅行为样例的响应式旅行规划 PWA。React、TypeScript、Vite、MapLibre、OpenFreeMap、IndexedDB。

## 本地运行

需要 Node.js 22+ 和 pnpm 11。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

正式产物位于 `dist/`，可通过 HTTPS 静态托管。`pnpm dev` 的地址是 `http://127.0.0.1:5173/`。PWA 服务工作线程仅在正式构建启用。

## 已实现

- 可缩放真实地图、原创 SVG 地标、两城 24 个精选景点、分类与搜索、景点/地图双向选择。
- 五日行程、景点拖入日期、跨日移动、时间编辑、上下排序、顺路建议和时间冲突提示。
- 三种打卡来源（演示、手动、前台定位）、六款动物头像、模拟同行者和手动/演示步数。
- 多币种账本、付款人与指定参与人均摊、每日参考汇率/手动输入、余额结算与冻结快照。
- 成就、照片本地上传与裁切、三种相框、900×1180 PNG 旅行明信片导出。
- IndexedDB 自动保存、应用界面离线缓存、窄屏地图与底部抽屉。

## 数据与明确边界

景点坐标及简介是精选原型资料；介绍参考 VisitOSLO、Visit Bergen 官方旅游页面，卡片保留来源。星级为编辑推荐。地图来自 OpenFreeMap / OpenMapTiles / OpenStreetMap，署名始终保留。

默认行程部分路线是预制示例轨迹；其他组合是直线连接和距离估算，均非导航或实时交通。交通、住宿入口跳往第三方，不获取库存、价格或执行预订。地理距离建议不考虑道路、渡轮、开放时间。

默认账目和初始汇率明确为演示资料。用户可从 Frankfurter 获取最新可用每日参考价（非交易实时报价），或手动指定汇率。费用按最小货币单位保存。尾差按稳定成员 ID 分配；结算冻结账目、成员、币种和汇率，不发起支付、不承诺最少转账次数。

数据与照片只在当前浏览器保存，不提供账号、真实邀请、多人或跨设备同步。清除站点数据会清除本地记录。头像为系统动物表情，地标为原创 SVG。定位仅在用户主动开启的旅行模式前台运行；切换模式、页面隐藏或卸载即停止。定位辅助打卡条件为距景点不超过 200 米且水平误差不超过 100 米。浏览器拒绝定位时仍能手动或演示打卡。未连接健康系统；步数始终标记为手动或演示。

照片不会发送到服务器。浏览器在线加载底图和字体；应用缓存不包含完整离线底图。正式站点需首次联网访问后才可离线打开。

## 代码结构

- `data.ts`：类型、景点和五日样例；`engine.ts`：费用、汇率、行程、成就计算。
- `adapters.ts`、`MapView.tsx`：数据/地图/路线边界及 MapLibre 渲染。
- `App.tsx`：规划与旅行模式；`Expenses.tsx`：记账结算；`Report.tsx`：Canvas 照片报告。
- `storage.ts`：IndexedDB 与本地图片缩放。

未来可替换适配层接入 POI 与交通服务，并在本地状态外增加具备权限检查的账号、邀请和同步服务。不得将当前模拟位置当作真实同行者位置。
